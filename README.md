# XO Game

A customizable Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Live Demo

[Play XO Game](https://ibrahim-almahdy.github.io/XO-Game/)

## Features

- Choose board size: 3×3, 4×4, 5×5, or 6×6
- Two-player gameplay
- X and O win counter
- Round system — first player to reach 5 wins wins the round
- Draw detection
- Reset and Back to Home buttons
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- CSS Grid
- DOM Manipulation
